# Netforma — генератор документации сети

## 1. Описание проекта

**Netforma** — веб-приложение для автоматизированной обработки данных о компьютерной сети и генерации её визуальной документации.

Приложение позволяет загрузить файл с описанием сети, обработать содержащиеся в нём данные и получить диаграмму сети в форматах PNG и PlantUML.

## 2. Основные возможности

- Загрузка файлов с описанием сети.
- Обработка и преобразование входных данных.
- Формирование статистики по хостам и соединениям.
- Генерация диаграмм сети с помощью PlantUML.
- Просмотр результатов в веб-интерфейсе.
- Скачивание диаграммы в формате PNG.
- Получение исходного кода PlantUML.

## 3. Технологии

- **Python** — основной язык программирования.
- **Flask** — серверная часть приложения.
- **HTML, CSS, JavaScript** — веб-интерфейс.
- **PlantUML** — генерация диаграмм.
- **Java** — запуск PlantUML.
- **GraphViz** — визуализация диаграмм.
- **python-dotenv** — загрузка настроек из `.env`.

### Назначение основных компонентов

- `run.py` — точка входа и запуск Flask-приложения.
- `app/__init__.py` — создание Flask-приложения и регистрация маршрутов.
- `app/routes.py` — обработка HTTP-запросов и взаимодействие с frontend.
- `app/pipeline.py` — объединение модулей обработки данных и генерации диаграмм.
- `data_loader.py` — загрузка входных файлов.
- `data_validator.py` — проверка корректности входных данных.
- `processing/models.py` — модели данных сети.
- `processing/converter.py` — преобразование данных в объекты моделей.
- `processing/processor.py` — обработка данных по выбранным профилям.
- `diagram_generator.py` — формирование и генерация диаграмм PlantUML.
- `static/` — JavaScript и CSS.
- `templates/` — HTML-страницы приложения.
- `output/` — результаты генерации.

## 5. Требования

Для запуска проекта необходимы:

- Python 3.13 или совместимая версия.
- Java Runtime Environment.
- PlantUML JAR.
- GraphViz.
- Зависимости из `requirements.txt`.

## 6. Установка проекта

Клонируйте репозиторий:

```bash
git clone <ссылка-на-репозиторий>
```

Перейдите в папку проекта:

```bash
cd network_doc_generator
```

Создайте виртуальное окружение:

```bash
python -m venv .venv
```

Активируйте его.

**Windows PowerShell:**

```powershell
.\.venv\Scripts\Activate.ps1
```

Установите зависимости:

```bash
python -m pip install -r requirements.txt
```

## 7. Настройка окружения

В корне проекта создайте файл `.env`.

Добавьте в него путь к установленному PlantUML JAR:

```env
PLANTUML_JAR=C:/путь/к/plantuml.jar
```

Укажите фактический путь к файлу на своём компьютере.

Файл `.env` не следует загружать в публичный репозиторий, поскольку он содержит локальные настройки.

## 8. Запуск приложения

Убедитесь, что виртуальное окружение активировано.

Запустите приложение командой:

```bash
python run.py
```

После запуска откройте в браузере:

```text
http://127.0.0.1:5000
```

## 9. Использование приложения

1. Откройте веб-интерфейс Netforma.
2. Перейдите к загрузке файла с описанием сети.
3. Выберите входной файл.
4. Выберите профиль генерации.
5. Запустите обработку.
6. Просмотрите полученную диаграмму.
7. Скачайте результат в формате PNG или PlantUML.

## 10. Результаты работы

В результате обработки пользователь получает:

- статистику по хостам и соединениям;
- диаграмму сети в формате PNG;
- исходный код диаграммы в формате PlantUML.

## 11. Разработка

Проект построен по принципу модульного монолита.

Серверная часть отвечает за загрузку, проверку и обработку данных, а также генерацию диаграмм. Веб-интерфейс взаимодействует с сервером посредством HTTP-запросов.

Основной процесс обработки объединён в `app/pipeline.py`.

## 12. Статус проекта

Проект находится в стадии разработки. Функциональность и поддерживаемые форматы входных данных могут расширяться.
