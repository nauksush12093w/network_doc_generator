# Генератор архитектурной документации по сетям

## Описание проекта

Приложение предназначено для автоматизации
создания архитектурной документации по сетям.

Входные данные:
- YAML
- JSON
- CSV

Результат работы:
- Схема сети в формате PlantUML
- Изображение схемы PNG (при поддержке генерации)

## Технологии

- Python
- Flask
- PyYAML
- HTML
- CSS
- JavaScript
- PlantUML

## Структура проекта

- app/ — серверная часть приложения
- app/components/ — функциональные модули
- app/templates/ — HTML-шаблоны
- app/static/ — CSS и JavaScript
- examples/ — примеры входных файлов
- output/ — результаты генерации
- tests/ — тесты
- docs/ — документация проекта

## Установка

1. Создать виртуальное окружение:

   python -m venv venv

2. Активировать окружение в Git Bash:

   source venv/Scripts/activate

3. Установить зависимости:

   python -m pip install -r requirements.txt

## Запуск

Выполнить команду:

python run.py

Открыть в браузере:

http://127.0.0.1:5000
